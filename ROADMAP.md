Блокер финальной проверки 0.3.1: сборка и lint проходят, но последний Android 14 эмулятор отключается от ADB без итогового отчёта. APK выпускается предварительно. Нужно восстановить стабильный прогон, проверить аппаратный рендеринг и испытать ARM64/голос/фон на POCO F4; предыдущий успешный прогон не считать проверкой последней версии.

Статус 0.3.1: испытательный выпуск. В 0.3.1 добавлены отдельный фоновой браузер с JavaScript/DOM/проверками и режим без device-инструментов, обновлён интерфейс на основе 0.2, настройки стекла, поиск/избранное моделей и шкала усилия. «Есть» означает реализованный путь в коде, а не совместимость со всеми моделями, телефонами и приложениями. Проверки выполняет CI; особенности POCO/HyperOS требуют испытания на устройстве.

## Приоритет следующего испытания

1. Установить APK на POCO F4/Android 14 и проверить Accessibility после перезапуска. При конфликте подписи старой версии сначала сохранить данные и ключи; автоматический перенос 0.2 не проверяется.
2. Встроенный Linux: установка пакетов, Python/Node/C/Git, интерактивная клавиатура/SSH, фон, Stop и свободное место. Никакой отдельной установки Termux.
3. Настоящий пользовательский проект: clone → небольшая правка → тесты → подтверждённый commit/push → GitHub Actions → скачанный APK. Не записывать секреты в URL clone, историю команд или код.
4. Проверить Codex/OpenCode отдельно для архитектуры и libc окружения; добавлять мастер установки только после реального запуска. Сам факт наличия npm не является проверкой CLI.
5. Проверить API/фото на реально доступных аккаунтах. Вход в браузер продолжает считаться браузерным входом, пока провайдер не предоставляет пригодный API/OAuth.

## Принцип ограничений

Не обещать системный root, обход «Ограниченных настроек», обход защищённых экранов, совместимость каждого Termux-пакета или доступ к API по произвольной веб-подписке. Для Android-системных команд реальная дополнительная возможность — отдельное разрешённое пользователем Shizuku/ADB-подключение. Для APK-сборок уже используется GitHub Actions. Полная виртуальная машина может понадобиться программам, несовместимым с PRoot, но в 0.3 её нет.
