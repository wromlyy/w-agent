# W Agent 0.3.1

**by @wromly** · Android 9+ · Java + локальный WebView · без root.

Чат с моделями, агент управления телефоном, работа с проектами, GitHub Actions и встроенный Linux-терминал. Это испытательная версия: реализованные возможности и оставшиеся пункты большого плана разделены ниже и в [ROADMAP.md](ROADMAP.md).

[APK и исходники релизов](https://github.com/wromlyy/w-agent/releases) · [Проверки GitHub Actions](https://github.com/wromlyy/w-agent/actions)

## Обновление 0.3.1

- Возвращены цвета и пропорции 0.2. **Настройки → Кастом**: Liquid Glass с размытием/прозрачностью, свой фон и акцент; предварительный просмотр отменяется без сохранения. Это локальный CSS-эффект стекла, а не системный интерфейс iOS.
- У сообщения — шкала **Авто / Low / Medium / High**, расширенные уровни по нажатию. Настройка сохраняется отдельно для модели; явно выбранный уровень больше не перезаписывается пресетом роли.
- Модели: поиск по провайдеру/имени, избранные сверху, переключение без потери черновика.
- Голос: видимая запись и промежуточный текст, завершение/отмена; после разрешения микрофона запись продолжается. Результат дописывается в черновик и не отправляется автоматически. Нужна установленная системная служба речи; физический микрофон проверяется на устройстве.
- Терминал — отдельная полноэкранная PTY-сессия. Нет формы команд/списка пакетов на основном экране; Esc/Ctrl/Tab/стрелки внизу, вставка/копирование/команда установки в меню. Вход через меню сразу открывает сессию. Чат и файлы проекта доступны отдельно.
- **Агент · в фоне**: свои браузер, проект и Linux-тесты без чтения и переключения экрана телефона. Можно пользоваться другим приложением. У режима нет инструмента device и выключена отправка снимков пользовательского экрана. Управление телефоном выбирается отдельно.
- Фоновый браузер исполняет JavaScript в отдельном WebView без Android bridge: публичный HTTPS или preview HTML из /workspace, DOM, click/type, assert, console и PNG-снимок. Это не сессия Chrome пользователя. Действия на внешних сайтах требуют подтверждения; локальный preview тестируется автоматически. Локальные HTTP dev-серверы и удалённый headless Chromium пока не поддерживаются.
- Внутренняя /workspace подключается автоматически. Локальные diff/checkpoints и Linux-команды/тесты выполняются без повторного запроса при **Авто для локальных задач**. Это доверие к коду с UID W Agent, а не OS sandbox. Прямые команды удаления, sudo/SSH, git push, установка через curl | sh и Android shell требуют отдельного подтверждения. Внешние SAF-папки сохраняют подтверждение изменений.
- Активная задача использует foreground-уведомление и ограниченный по времени WakeLock. При завершении браузер уничтожается. Android/HyperOS всё ещё может завершить приложение; телефон не является постоянно доступным сервером.

## Новое в 0.3

### Агент

- Отдельные режимы **Чат / Агент**, продолжающаяся переписка, копирование сообщений и блоков кода, история чатов.
- Цикл вызова инструментов с результатами и проверками. Лимиты действий, времени и токенов, остановка повторяющихся вызовов, смена подхода при неизменившемся экране.
- Ожидаемый текст/приложение после экранного действия сверяются с новым деревом Accessibility. Это не универсальная визуальная проверка любого экрана.
- Режим планирования: редактирование плана перед запуском. Planner → Executor → Reviewer — последовательные запросы к модели, а не независимые фоновые агенты. Reviewer может потребовать исправление; после двух корректирующих проходов неподтверждённый результат помечается отдельно.
- Потоковый текст OpenAI-compatible/Responses и Anthropic; Gemini пока возвращает ответ целиком. Карточки действий и результатов, пауза и остановка через интерфейс, уведомление и оверлей.
- «Подумай дважды», профили ролей, уровни рассуждений, бюджет и блок reasoning, если провайдер действительно его возвращает. Скрытые внутренние рассуждения приложение не извлекает.
- Пресеты General, Code, Python, Frontend, Debugger, Reviewer, Architect, Phone Operator, Researcher, Writer. Собственные роли в JSON: инструкции, модель, инструменты и правила подтверждений. Reviewer/Architect имеют нативно проверяемые ограничения записи.

### Linux внутри приложения

Отдельный Termux **не нужен**. APK включает PRoot и Alpine 3.22.8 для **arm64-v8a / x86_64**. При первом запуске окружение распаковывается локально с проверкой SHA-256. Версия Android/target SDK не понижается ради запуска команд.

- Терминал команд: stdout/stderr, код завершения, таймаут 1–600 секунд, процессы, Kill, сохранённая история команд. Агент вызывает тот же механизм через `shell_exec`.
- Интерактивная PTY-сессия с xterm.js: постоянный shell, клавиатура, Esc/Tab/Ctrl-C/Ctrl-D, стрелки, изменение размера. Сессия имеет отдельное foreground-уведомление и кнопку остановки.
- Рабочие файлы доступны в `/workspace`; пакеты и Linux HOME сохраняются между запусками. Отдельные команды `shell_exec` запускают новый shell: `cd` и переменные между такими вызовами не сохраняются. Для постоянного состояния используйте PTY.
- Пакетный менеджер **Alpine apk**. `pkg` — небольшой совместимый помощник для install/uninstall/update/upgrade/search/list-installed с именами пакетов Alpine. Это не репозиторий пакетов Termux и не обещание совместимости каждой его команды.

```sh
pkg update
pkg install python3 py3-pip nodejs npm git openssh build-base
python3 --version
node --version
git --version
```

Пакеты загружаются по запросу; для этого нужны интернет и место на диске. Python, Node, Git, SSH, компиляторы, Codex/OpenCode и Android SDK не встроены в начальный rootfs. Наличие пакета и совместимость конкретной версии CLI проверяются запуском. Проекты APK рекомендуется собирать на GitHub Actions.

Можно переключиться на системный `/system/bin/sh`. Ни один режим не получает UID `shell`, Android root или доступ к чужим приватным данным. `pm`, `input`, `settings`, `logcat` ограничены правами приложения. PRoot не является границей безопасности: shell-команда работает с UID W Agent. В 0.3.1 команды доверенных локальных задач разрешены настройкой autoLocal; остальные требуют подтверждения; ручной ввод в PTY выполняется сразу после открытия сессии с предупреждением. Название режима доверия роли не создаёт OS sandbox. Kill не гарантирует завершение отделившихся потомков; Android также может завершить процесс при нехватке памяти.

Исходники, лицензии, патчи и инструкции сборки компонентов: [third_party/linux-runtime](third_party/linux-runtime/README.md). Архив **W-Agent-Linux-Sources.tar.gz** публикуется рядом с APK и отдельным артефактом CI.

### Проекты, файлы и GitHub

- Выбор папки через Android Storage Access Framework, чтение/создание/копирование/перемещение файлов, выдача результата в чат с «Сохранить» и «Поделиться».
- Проект: `read_file`, `write_file`, `edit_file`, `list_dir`, буквальный рекурсивный `grep`. Строгий unified diff; предварительный просмотр, подтверждение, проверка актуальности исходника, перечитывание после записи.
- Зашифрованные checkpoints **отдельных текстовых файлов** и откат с защитой от перезаписи новых правок. Это не снимок всего репозитория.
- Кнопка **Linux workspace** подключает настоящую папку терминала к файловому браузеру, редактору, diff/checkpoints и выдаче файлов в чат. Она также доступна через системный SAF-провайдер W Agent после выбора пользователем. Символические ссылки провайдер не открывает.
- Текстовый редактор с вкладками и поиском. Подсветка синтаксиса есть в Markdown-коде, но редактор пока не IDE с анализом проекта.
- Корневой AGENTS.md/W-AGENT.md и зашифрованная Project Memory добавляются в контекст. Вложенные инструкции нужно читать явно: полного автоматического обхода AGENTS.md ещё нет.
- Личная память: сохранение с подтверждением, просмотр, удаление. Не предназначена для паролей и токенов.
- `github_actions`: список workflows, запуск, получение run/jobs/artifacts, отмена, скачивание ZIP и выбор настоящего APK из артефакта. Запуск workflow не выдаётся за успешную сборку: агент должен проверить завершение, commit и результат.
- GitHub REST подключается отдельным PAT. Права зависят от токена; для сборок нужны Actions read/write и доступ к репозиторию. Git-операции доступны через установленный Git в Linux и подключённый REST API, отдельных обёрток `git_*` пока нет. Внешняя SAF-папка не является POSIX-монтированием для Git: Linux-проект находится в `/workspace`, а кнопка Linux workspace открывает ту же папку через SAF. Файлы из других SAF-папок передаются файловыми инструментами.

### Удобство и данные

- Использование токенов по провайдерам/моделям. Стоимость показывается только если API её вернул; выдуманной оценки нет. Если usage отсутствует, бюджет использует приближение, а не точный счёт провайдера.
- Индикатор контекста и явное сжатие истории с сохранением полной видимой переписки. Библиотека промптов с переменными.
- Голосовой ввод через SpeechRecognizer и озвучка через TextToSpeech, если сервисы доступны на устройстве.
- Очередь задач, сохранение успешной цепочки как макроса и повтор без вызова модели с обычными подтверждениями. Макросы не считаются проверенными для другого экрана или версии приложения.
- Однократные/повторные **напоминания** WorkManager: уведомление открывает черновик задачи, запуск подтверждает пользователь. Это не скрытое автономное управление телефоном по расписанию; время зависит от ограничений Android.
- Share → W Agent для текста, изображения и PDF, Quick Settings tile. Публичное чтение HTTPS-страниц без JavaScript/сессии браузера, отдельный поиск через подключённый Brave Search API.
- Темы: светлая, тёмная, AMOLED, акцент/Material You (Android 12+), размер шрифта и плотность. Локальный Markdown с таблицами, подсветкой и копированием кода; HTML очищается DOMPurify.
- Разрешённые/запрещённые приложения для инструментов Accessibility, журнал вызовов и поиск. Список не является системным запретом для сторонних процессов/API.
- Экспорт/импорт настроек, ролей, навыков и промптов: обычный JSON без секретов либо файл с PBKDF2/AES-GCM по паролю. История, память и Android-разрешения в этот перенос настроек не входят.

## Сохранено из 0.2

- Accessibility: дерево экрана, нажатия, текст, прокрутка, жесты, системные кнопки, запуск приложений и HTTPS-ссылок. Снимки экрана опциональны, Android 11+, защищённые окна могут их запретить.
- Relay, OpenAI/Responses, Anthropic, Gemini, Kimi/Moonshot, DeepSeek, Qwen, OpenRouter, Groq, Mistral, xAI и свой совместимый API. Ручное имя модели и каталог сервера; поддержка инструментов/изображений зависит от модели и тарифа.
- Каталог бесплатных OpenRouter-моделей с проверкой нулевых цен и ограничением платной маршрутизации, официальный OpenRouter PKCE-вход.
- MCP HTTPS Streamable HTTP: JSON/SSE-ответы, tools, resources и prompts. HTTP-сервисы, навыки SKILL.md и собственные инструкции.
- Вложения: до 6 файлов, подготовленный файл до 4 МБ, всего до 10 МБ; текст до 200 КБ. Фото до 20 МБ перед подготовкой нормализуется в JPEG до 1600 px и лимита вложения, включая HEIC при поддержке Android. Распознавание выполняет выбранная vision-модель. Изображения старого сеанса нужно приложить повторно; PDF требует поддержки API.
- Ключи, токены, история и конфигурация шифруются AES-GCM ключом Android Keystore. Локальный интерфейс без CDN; Android bridge недоступен удалённым страницам.

## Подключение и ограничения аккаунтов

1. Установите APK. Для POCO F4 нужен ARM64; отдельный Termux не требуется.
2. **Связи → Модели**: OpenRouter PKCE или API-ключ выбранного провайдера. Кнопка проверки делает настоящий небольшой API-запрос и может расходовать квоту.
3. **Настройки → Управление телефоном**: разрешите Accessibility вручную. На Android 13+ установке из APK иногда требуется «Разрешить ограниченные настройки» в системной карточке приложения. W Agent не обходит этот экран.
4. **Файлы**: подключите нужную папку. **Связи → Сервисы**: GitHub PAT, MCP или свой HTTPS API.
5. Выберите Чат/Агент, роль и при необходимости планирование. Для действий на телефоне держите его разблокированным и экран включённым.

Вход в сайт ChatGPT/Gemini/Grok/Claude в браузере **не подключает API к агенту**. Подписка и браузерные cookies не являются API-ключом. Универсального официального OAuth для всех этих сервисов здесь нет; автоматическое извлечение браузерных сессий не реализовано. Подключёнными считаются реальные API-настройки; OpenRouter имеет отдельный поддерживаемый PKCE-процесс. Relay: `https://codex-relay.codes/v1`, ключ берётся в кабинете сервиса.

Приложение не управляет гарантированно каждым экраном YouTube, TikTok, игр или банковских приложений: часть интерфейсов скрывает дерево/снимки. MIUI/HyperOS может ограничивать Accessibility, уведомления и фоновые процессы. Эмулятор Android 14 не заменяет проверку на POCO F4. Ошибки подключения показываются отдельно от включённого переключателя сервиса; приложение не объявляет подключением один лишь флаг настройки.

MCP OAuth, локальные/stdio MCP-серверы, Shizuku/беспроводной ADB, Chaquopy, NotificationListener/ответы, виджет, IME и полная английская локализация пока отсутствуют. Полный статус остальных пунктов — в [ROADMAP.md](ROADMAP.md).

## Сборка и проверки

Статус предварительной 0.3.1: debug/release сборки, lint и UI/logic тесты прошли в [42523404879](https://github.com/wromlyy/w-agent/actions/runs/42523404879). Итоговый тест Android 14 не прошёл: эмулятор пропадает из ADB без отчёта. Предыдущий прогон [42516954953](https://github.com/wromlyy/w-agent/actions/runs/42516954953) успешен, но не заменяет проверку финального APK. В последнем тесте аппаратное ускорение Activity отключается только из instrumentation; установленный APK сохраняет обычный рендеринг. Микрофон, графика и POCO/HyperOS ещё требуют проверки на физическом устройстве.

Нужны Node.js 22+, JDK 17, Android SDK Platform 35, Build Tools 35.0.0, Android NDK 27.2.12479018 (Linux x86_64 для скрипта PTY), tar/xz и интернет для закреплённых зависимостей:

```sh
npm ci --ignore-scripts
npm test
node tools/prepare-linux.cjs
sh tools/build-pty.sh
sh gradlew assembleDebug lintDebug testDebugUnitTest
```

SDK задаётся через `ANDROID_HOME`/`ANDROID_SDK_ROOT`. Gradle Wrapper 8.13, AGP 8.9.2, min SDK 28, target SDK 35. Debug APK: `app/build/outputs/apk/debug/app-debug.apk`. Для релиза CI также выполняет `assembleRelease lintRelease`; публикуется подписанный `app/build/outputs/apk/release/app-release.apk` с `debuggable=false` и SHA-256. Без Android SDK локальная Gradle-сборка невозможна; в этой среде полные проверки выполняются на GitHub Actions.

CI запускает тесты UI и API/логики, Chrome-превью, сборку и lint, затем тестирует именно release APK на одноразовом эмуляторе Android 14: Accessibility reconnect/оверлей, упакованный WebView, файловый провайдер, SAF diff/rollback, нормализация фото, Linux-команды/таймаут, установка пакетов, запуск Python/Node/Git/SSH, компиляция и исполнение C, PTY/resize/exit, двусторонний доступ SAF↔Linux workspace и запрет перехода по симлинку вне папки. Для сетевой установки пакетов эмулятору нужен доступ к репозиторию Alpine. Исходники runtime публикуются отдельным артефактом.

Ключ подписи CI хранится в GitHub secret `W_AGENT_DEBUG_KEYSTORE_BASE64` и используется по явно заданному пути для новых сборок. Совместимость подписи с ранее опубликованной 0.2 не гарантируется: при конфликте Android потребует переустановку; перед удалением сохраните необходимые данные и API-ключи. Приватный ключ не входит в репозиторий или архив исходников. Публикация в Google Play потребует отдельной проверки правил Accessibility, выполнения кода и распространения пакетов.

## Исходники и лицензии

`app/src/main/java/dev/wagent/` — Android bridge, агент, провайдеры API, инструменты, службы и хранилище. `app/src/main/cpp/pty.c` — небольшой собственный JNI PTY bridge. `app/src/main/assets/` — локальный UI и векторные иконки. Скрипты сборки/проверок — `tools/`.

W Agent: MIT. Независимые компоненты сохраняют свои лицензии: PRoot/talloc/Alpine — [runtime notices](third_party/linux-runtime/README.md); xterm.js/fit, marked, DOMPurify и highlight.js — лицензии в `third_party/`. Логотипы [Lobe Icons](https://github.com/lobehub/lobe-icons) MIT (`@lobehub/icons-static-svg` 1.102.0); Relay favicon принадлежит владельцу сервиса.

Документация: [OpenRouter PKCE](https://openrouter.ai/docs/guides/overview/auth/oauth), [бесплатные модели](https://openrouter.ai/docs/guides/routing/model-variants/free), [OpenAI function calling](https://developers.openai.com/api/docs/guides/function-calling), [PRoot](https://github.com/termux/proot), [Alpine packages](https://pkgs.alpinelinux.org/packages). Модели работают у настроенного провайдера; их веса в APK не входят.
