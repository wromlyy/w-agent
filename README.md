# W Agent

Android-приложение для работы с моделями ИИ и выполнения задач на телефоне. Локальный интерфейс на русском языке, светлая и тёмная темы, управление через Android Accessibility Service. Android 9+; без root.

## Что есть в версии 0.1

- Чат с агентом, последовательное выполнение инструментов, видимая история шагов, остановка поверх приложений и через уведомление.
- Чтение элементов открытого экрана, нажатия, ввод текста, прокрутка, жесты, системные кнопки, запуск приложений и HTTPS-ссылок.
- Список установленных приложений с их значками. Быстрые запросы для YouTube, TikTok, браузера и GitHub.
- Несколько API-подключений. Шаблоны Relay, OpenAI, Anthropic, Gemini, Kimi/Moonshot, DeepSeek, Qwen, OpenRouter, Groq, Mistral, xAI и собственного сервера.
- Три формата API: OpenAI Chat Completions с function calling, Anthropic Messages, Google Gemini generateContent. Название модели вводится вручную или выбирается из списка сервера. Поддержка конкретной модели зависит от её API, прав ключа и поддержки инструментов.
- Сторонние сервисы: HTTPS API с Bearer-токеном, шаблон GitHub REST API и MCP Streamable HTTP. Агент может получать список инструментов MCP и вызывать их, читать ресурсы и получать промпты. Изменяющие HTTP-запросы и вызовы инструментов MCP требуют подтверждения.
- Навыки: создание, редактирование, включение, импорт `SKILL.md`, готовые шаблоны. Навыки добавляют инструкции модели; скрипты и пакеты из них не исполняются.
- Вложения: текст, Markdown, исходный код, JSON, CSV, изображения и PDF. До 6 файлов, 4 МБ на файл, 10 МБ всего; текст до 200 КБ. Изображения/PDF требуют поддержки выбранной моделью и провайдером.
- Опциональные снимки экрана (Android 11+). Выключены по умолчанию. Парольные поля в доступном дереве маскируются; защищённые Android-экраны могут не давать снимок.
- Локальная история и экспорт истории в JSON. API-ключи, токены, навыки и история шифруются AES-GCM ключом Android Keystore. Ключи не входят в экспорт и исходники.

## Установка

1. Скачайте `W-Agent.apk` из Releases или артефакт `W-Agent-APK` из успешной сборки во вкладке Actions.
2. Установите APK. В Android разрешите установку файлов этому браузеру или файловому менеджеру, если система попросит.
3. В W Agent откройте **Связи → Модели → Добавить**, выберите провайдера, введите API-ключ и точное имя модели. Кнопка «Получить список» запрашивает доступные модели у провайдера.
4. Для управления приложениями включите **Настройки → Управление телефоном → W Agent** в специальных возможностях Android. На некоторых версиях Android 13+ для APK, установленного из файла, нужно сначала открыть системную карточку W Agent и в меню разрешить ограниченные настройки. Это действие выполняется вручную.
5. Опишите задачу в чате. Разблокируйте телефон и держите экран включённым. Кнопка **W · Остановить** остаётся поверх приложений во время выполнения.

Подписка ChatGPT/Claude сама по себе не заменяет API-ключ провайдера. Relay: `https://codex-relay.codes/v1`; ключ создаётся в его кабинете. Для GitHub создайте отдельный personal access token с нужными правами и добавьте его в **Связи → Сервисы → GitHub**.

## Практические ограничения

Версия 0.1 — первая версия для испытания на устройстве. Нет гарантии управления любым экраном любого приложения: игры, защищённые окна и некоторые интерфейсы видео-приложений могут скрывать элементы. Снимки и жесты помогают, но требуют подходящей модели. Автоматический вход, обход блокировки и выдача системных разрешений не поддерживаются. Операции отправки/публикации по распознанным кнопкам запрашивают подтверждение; распознавание кнопок зависит от текста интерфейса и не заменяет контроль пользователя.

Задачи выполняются только после запуска пользователем. Активная задача держит foreground service с уведомлением. W Agent не имеет отдельного сервера: текст, файлы и разрешённые снимки отправляются прямо настроенному провайдеру, запросы сервисов — прямо настроенным адресам. Настройки сервисов не передаются модели вместе с секретами; модель получает только название, адрес, описание и идентификатор подключения.

MCP поддерживает HTTPS Streamable HTTP с JSON или SSE-ответами. Старый двухканальный SSE-транспорт, stdio, OAuth-авторизация MCP и локальные HTTP-серверы в этой версии не реализованы. Подключение GitHub внутри APK использует персональный токен, а не OAuth. Озвучка, голосовой ввод, выполнение shell-команд и генерация изображений отдельными image API не реализованы.

## Сборка

Нужны JDK 17, Android SDK Platform 35 и Build Tools 35.0.0:

```sh
sh gradlew assembleDebug lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Gradle Wrapper 8.13, Android Gradle Plugin 8.9.2. Workflow `.github/workflows/android.yml` автоматически собирает APK при push в `main`; результаты lint публикуются отдельным артефактом. Сборка не содержит API-ключей.

GitHub Actions использует один ключ подписи из секрета `W_AGENT_DEBUG_KEYSTORE_BASE64`, если он настроен. Это позволяет обновлять APK поверх предыдущих сборок этого репозитория. Для публикации в магазине требуется отдельный release-процесс и соблюдение правил магазина для Accessibility API.

## Структура

`app/src/main/java/dev/wagent/`: Android bridge, агент, адаптеры API, сервис управления, MCP/HTTP и зашифрованное хранилище. `app/src/main/assets/`: локальный интерфейс без CDN, векторные иконки и логотипы. Веб-интерфейс не загружает удалённые скрипты и не предоставляет Android bridge внешним страницам.

Логотипы провайдеров: [Lobe Icons](https://github.com/lobehub/lobe-icons), MIT, версия npm `@lobehub/icons-static-svg` 1.102.0. Лицензия в `third_party/lobe-icons-LICENSE`. Логотип Relay взят с `https://codex-relay.codes/favicon.svg` для обозначения подключаемого сервиса; принадлежит его владельцу. Названия и логотипы принадлежат соответствующим правообладателям.

Документация формата инструментов: https://developers.openai.com/api/docs/guides/function-calling. Настройка Relay сверена с его разделом Quick start и публичным адресом сервера.
